# Kilo — 极简终端文本编辑器

一个用纯 C 编写的轻量级终端文本编辑器，单文件、零依赖。

---

## ✨ 特性

- **单文件零依赖**：仅需 `kilo.c` 和标准 C 库即可编译
- **完整编辑**：插入、删除、Backspace、回车拆行、Tab 自动渲染为空格
- **光标导航**：方向键、`Home` / `End`、`Page Up` / `Page Down`
- **文件操作**：打开文件、保存到磁盘（`Ctrl+S`），新文件支持命名提示
- **实时搜索**：增量查找，边输入边匹配（`Ctrl+F`），支持方向键切换匹配项
- **状态栏**：显示文件名、行数、修改状态与当前光标位置
- **安全退出**：未保存时 `Ctrl+O` 会提示确认，防止误操作

---

## 🚀 快速开始

### 编译

```bash
gcc -o kilo kilo.c -Wall -Wextra -std=c99
```

### 运行

```bash
./kilo                    # 打开空文件
./kilo hello.txt          # 打开或创建指定文件
```

---

## ⌨️ 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + S` | 保存文件（无文件名时提示输入） |
| `Ctrl + O` | 退出编辑器（未保存需多次确认） |
| `Ctrl + F` | 搜索文本（增量搜索，方向键切换匹配） |
| `↑ ↓ ← →` | 移动光标 |
| `Home` / `End` | 跳到行首 / 行尾 |
| `Page Up` / `Page Down` | 向上 / 向下翻页 |
| `Backspace` / `Delete` | 删除字符 |
| `Esc` | 取消当前操作（搜索/保存提示） |
